# React User Form

A React controlled form with live preview, built with Vite and CSS.

🔗 Live Demo:
[Open the app](https://react-user-form-1lwaobg51-saniya-talikoti.vercel.app)

<img width="304" height="429" alt="image" src="https://github.com/user-attachments/assets/317796c2-5750-4feb-bf42-cdb87ea99ddd" />










## Features
- Controlled components with `useState`
- Name auto-converts to uppercase
- Live preview of entered data
- Toggle switch and email validation chip
- Responsive, modern glass UI

## Run locally
```bash
npm install
npm run dev
```
